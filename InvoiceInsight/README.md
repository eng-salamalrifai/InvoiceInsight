# InvoiceInsight

### نظام ذكي لإدارة الفواتير واكتشاف الحالات المالية غير المعتادة

**InvoiceInsight** هو تطبيق مكتبي مبني باستخدام C# وWPF، يهدف إلى تسهيل إدارة الفواتير والموردين، واستيراد بيانات الفواتير من Excel، وتحليل البيانات المالية لاكتشاف القيم والأنماط غير المعتادة.

## المميزات الرئيسية

- **إدارة الفواتير:** إضافة سجلات الفواتير وتنظيمها وربطها بالموردين.
- **إدارة الموردين:** حفظ بيانات الموردين وتحليل الإنفاق المرتبط بهم.
- **استيراد Excel:** استيراد الفواتير ومعاينتها والتحقق من بياناتها واكتشاف التكرارات قبل الحفظ.
- **اكتشاف الحالات غير المعتادة:** إصدار تنبيهات عند اكتشاف فواتير مكررة أو مبالغ مرتفعة بشكل غير معتاد.
- **لوحة التحكم:** عرض إحصائيات الفواتير، والنشاط الشهري، والإنفاق حسب المورد، والفواتير الأعلى قيمة.

## التقنيات والمكتبات

| التقنية / المكتبة | الاستخدام |
|---|---|
| C# / .NET 10 | تطوير التطبيق |
| WPF / XAML | واجهة المستخدم |
| Entity Framework Core 10 | إدارة البيانات |
| MySQL | قاعدة البيانات |

## البنية المعمارية

يعتمد المشروع على تنظيم يفصل بين الواجهة ومنطق العمل وإدارة البيانات:

```text
InvoiceInsight/
├── Models/       # نماذج البيانات
├── Data/         # سياق قاعدة البيانات
├── Services/     # منطق العمل والخدمات
├── ViewModels/   # منطق العرض
├── Views/        # واجهات المستخدم
├── Seeds/        # البيانات الأولية
├── Migrations/   # تحديثات قاعدة البيانات
├── App.xaml
├── MainWindow.xaml
└── InvoiceInsight.csproj
```

## ملف Excel التجريبي

يتضمن المشروع ملف Excel باسم **`invoice-ex.xlsx`** لاستخدامه مباشرة في تجربة ميزة استيراد الفواتير.

يحتوي الملف على الأعمدة التالية:

| اسم العمود | الوصف |
|---|---|
| `Invoice Number` | رقم الفاتورة |
| `Supplier Name` | اسم المورد |
| `Invoice Date` | تاريخ الفاتورة |
| `Amount` | قيمة الفاتورة |

يمكنك تحميل الملف وفتحه باستخدام Excel، أو استيراده مباشرة من داخل التطبيق دون الحاجة إلى إنشاء ملف جديد.

## متطلبات التشغيل

- Windows
- Visual Studio 2022 أو إصدار متوافق
- .NET 10 SDK
- MySQL Server

## طريقة التشغيل

**1. تحميل المشروع**

```bash
git clone <YOUR_REPOSITORY_URL>
cd InvoiceInsight
```

**2. استعادة المكتبات**

```bash
dotnet restore
```

**3. إعداد قاعدة البيانات**

شغّل MySQL وأنشئ قاعدة البيانات:

```sql
CREATE DATABASE invoice_insight_db;
```

ثم اضبط بيانات الاتصال بقاعدة البيانات في إعدادات المشروع.

مثال:

```text
Server=localhost;
Port=3306;
Database=invoice_insight_db;
User=root;
Password=YOUR_PASSWORD;
```

**4. إنشاء جداول قاعدة البيانات**

من Package Manager Console في Visual Studio:

```powershell
Update-Database
```

**5. تشغيل التطبيق**

```bash
dotnet run
```

أو شغّل المشروع مباشرة من Visual Studio.
