InvoiceInsight

نظام ذكي لإدارة الفواتير واكتشاف الحالات المالية غير المعتادة

InvoiceInsight هو تطبيق مكتبي تم تطويره باستخدام C# وWPF لمساعدة فرق المحاسبة على إدارة الفواتير، وتنظيم بيانات الموردين، واستيراد بيانات الفواتير من ملفات Excel، واكتشاف المعاملات المالية التي قد تتضمن قيماً أو أنماطاً غير معتادة.

يهدف التطبيق إلى تبسيط عمليات إدارة الفواتير، وتوفير رؤية أوضح للبيانات المالية من خلال واجهة استخدام سهلة، ومخططات بيانية تفاعلية، ونظام تنبيهات يساعد المحاسبين على مراجعة الحالات التي تستدعي الانتباه.

---

المميزات الرئيسية

1. إدارة الفواتير (Invoice Management)

- إدارة سجلات الفواتير من خلال قاعدة بيانات مركزية.
- تخزين بيانات الفاتورة، بما يشمل رقم الفاتورة وتاريخها وقيمتها والمورد المرتبط بها.
- ربط كل فاتورة بالمورد الخاص بها.
- الاحتفاظ بسجلات الفواتير لاستخدامها في التحليل والتقارير.

2. إدارة الموردين (Supplier Management)

- إضافة وإدارة بيانات الموردين.
- ربط الموردين بالفواتير الخاصة بهم.
- تحليل نشاط الفواتير والإنفاق لكل مورد.

3. استيراد البيانات من Excel

- استيراد بيانات الفواتير من ملفات Excel.
- معاينة السجلات المستوردة قبل حفظها.
- التحقق من صحة بيانات الفواتير.
- اكتشاف السجلات المكررة المحتملة.
- مراجعة البيانات وتصحيحها قبل إضافتها إلى قاعدة البيانات.

4. التنبيهات المالية واكتشاف الحالات غير المعتادة

يساعد النظام على اكتشاف الفواتير التي قد تحتوي على أنماط أو قيم غير معتادة، وإنشاء تنبيهات لمراجعتها من قبل المحاسب.

من أمثلة الحالات التي يمكن اكتشافها:

- تكرار سجلات الفواتير.
- ارتفاع قيمة الفاتورة بشكل غير معتاد.
- وجود أنماط أو بيانات غير متوقعة في الفواتير.

يمكن ربط كل تنبيه بفاتورة محددة وتحديد ما إذا تمت مراجعته، مما يساعد على متابعة الحالات التي تتطلب اهتماماً.

5. لوحة التحكم والتحليل المرئي (Dashboard)

توفر لوحة التحكم نظرة عامة على نشاط الفواتير والبيانات المالية، وتتضمن:

- إجمالي عدد الفواتير.
- إجمالي القيمة المالية للفواتير.
- عدد الموردين.
- تحليل نشاط الفواتير الشهري.
- تحليل الإنفاق حسب المورد.
- عرض الفواتير الأعلى قيمة.

│   └── ...

ملاحظة: يعرض هذا المخطط التنظيم الأساسي للمشروع، وقد تختلف أسماء بعض الملفات أو تفاصيل المجلدات بحسب النسخة الحالية.

مكونات البنية المعمارية

Models — نماذج البيانات

- تمثيل الكيانات الأساسية في النظام.
- تحديد العلاقات بين الفواتير والموردين والتنبيهات.

Data — إدارة البيانات

- يحتوي على إعدادات وسياق قاعدة البيانات باستخدام Entity Framework Core.
- يدير الكيانات والعلاقات بينها.

Services — الخدمات

- يحتوي على منطق العمل والعمليات الأساسية.
- يتولى معالجة البيانات واسترجاع معلومات لوحة التحكم واستيراد ملفات Excel.

ViewModels — نماذج العرض

- إدارة منطق العرض والبيانات المقدمة لواجهة المستخدم.
- الربط بين الواجهات والخدمات.

Views — الواجهات

- تحتوي على واجهات المستخدم المبنية باستخدام WPF وXAML.

Seeds — البيانات الأولية

- تنظيم البيانات الأولية أو التجريبية المستخدمة أثناء التطوير.

Migrations — تحديثات قاعدة البيانات

- تتبع التغييرات التي تطرأ على مخطط قاعدة البيانات باستخدام Entity Framework Core.

تصميم قاعدة البيانات (Database Design)

يستخدم التطبيق قاعدة بيانات MySQL لتخزين البيانات وإدارة العلاقات بين الكيانات الأساسية.

الكيانات الرئيسية

الكيان| الوصف
"Invoice"| تخزين بيانات الفواتير، مثل الرقم والتاريخ والقيمة والمورد المرتبط بها.
"Supplier"| تخزين بيانات الموردين وإدارة علاقتهم بالفواتير.

العلاقات بين الكيانات

- يمكن للمورد الواحد امتلاك عدة فواتير.
- ترتبط كل فاتورة بمورد واحد.

طريقة التثبيت والتشغيل (Installation & Setup)

1. تحميل المشروع

استنسخ المستودع باستخدام الأمر التالي:

git clone <YOUR_REPOSITORY_URL>

انتقل إلى مجلد المشروع:

cd InvoiceInsight

2. فتح المشروع

افتح ملف "InvoiceInsight.sln" باستخدام Visual Studio، أو افتح ملف المشروع ".csproj" مباشرة.

استعد المكتبات والحزم المطلوبة:

dotnet restore

3. إعداد قاعدة البيانات

شغّل MySQL باستخدام Laragon.

أنشئ قاعدة البيانات التالية:

CREATE DATABASE invoice_insight_db;

بعد ذلك، اضبط Connection String في المكان المخصص لإعدادات قاعدة البيانات داخل المشروع.

مثال:

Server=localhost;
Port=3306;
Database=invoice_insight_db;
User=root;
Password=YOUR_PASSWORD;

استبدل بيانات الاتصال بما يتوافق مع إعدادات MySQL المحلية لديك.

4. إنشاء جداول قاعدة البيانات

افتح Package Manager Console داخل Visual Studio ونفّذ:

Update-Database

أو باستخدام أداة Entity Framework CLI، إذا كانت مثبتة:

dotnet ef database update

تقوم هذه الخطوة بإنشاء أو تحديث جداول قاعدة البيانات وفقاً لملفات Migration الموجودة في المشروع.

5. تشغيل التطبيق

يمكنك بناء المشروع وتشغيله مباشرة من خلال Visual Studio.

أو باستخدام الأمر:

dotnet run
